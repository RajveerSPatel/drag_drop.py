# Lesson Planner

A web-based lesson planning application that allows users to:

- View a calendar by month, term and year
- Navigate between dates
- View daily lesson schedules
- Create and edit lessons
- Organise lessons by year level
- Access the lesson library
- Navigate between the Calendar, Lesson Library and Lesson Creator

# Running the Application

This project can be run locally using the Visual Studio Code Live Server extension.

1. Open the `lesson-planner` folder in Visual Studio Code.
2. Open `calendar.html`.
3. Right-click the file.
4. Select **Open with Live Server**.
5. The application will open in your web browser.

The main page is:

`calendar.html`
